# Владение исходящими пакетами ENet

Небольшая C#-граница для managed function pointer, который принимает yENet в `EnetPacket.Create`. Сам адаптер, poll, маршруты и управление соединениями остаются в F# `EnetTransport`.

Перед созданием пакета резервируются число пакетов и байты полезной нагрузки для peer и host. `GCHandle` удерживает lease в `userData`. Последний release пакета ENet — после ACK, отказа отправки, reset или освобождения host — вызывает callback, освобождает handle и возвращает оба бюджета. Если пакет не создан или peer его не принял, `TrySend` сам освобождает handle и возвращает бюджеты. Все эти действия принадлежат одному владельцу ENet; дополнительных lock нет.

`MaxWaitingData` ENet ограничивает входящие ожидающие данные. `ReliableDataInTransit` не включает ещё не отправленные команды. Поэтому эти счётчики не используются как предел исходящей памяти. Наши лимиты учитывают сохраняемую ENet полезную нагрузку, включая ещё не подтверждённые пакеты; заголовки и служебные структуры ENet сюда не входят.

Штатный Close использует DisconnectLater и сохраняет отображение соединения до Disconnect. Единственный дедлайн принадлежит ServerRuntime; Reset принудительно завершает транспорт после него. Dispose вызывается после Completion владельца runtime и освобождает оставшиеся пакеты при аварии.


`TransportDiagnostics` применяет `Server.ReceiveBufferBytes` / `SendBufferBytes`
(по умолчанию 256 KiB, как у установленного xENet) и читает фактические размеры
через заимствованный socket handle. Обёртка не владеет сокетом и не закрывает его.
Размеры проверяются вместе с конфигурацией, буферы задаются сразу после создания host;
отказ setsockopt останавливает запуск транспорта.
При подключённом MeterListener метрики `Dreamsleeve.Transport` измеряют Poll,
постановку пакетов и раз в 100 мс — очереди/RTT/счётчики ENet. Все обращения к
host/peer происходят на владельце транспорта. Эти метрики не вводят отдельного агента.
`EnetPeerTrace` — диагностика по выбору: при подключённых метриках и переменной окружения
`DREAMSLEEVE_ENET_TRACE_DIRECTORY` пишет в JSONL состояние peer, чей неподтверждённый пакет ждёт
дольше 250 мс (RTT, окна, очереди команд; без полезной нагрузки, не более 20000 записей).

`OutgoingPackets.TrySend` получает канал и reliability от классификатора протокола:
Control/Chat reliable, Realtime sequenced flags=0. Предел realtime проверяется
до admission по согласованному payload MTU; reliable snapshot может фрагментироваться.
Неизвестное значение CLR enum `PacketDelivery` возвращает `InvalidDelivery` до
обращения к native peer, резервирования бюджетов и создания packet lease.
Для F# transport это ошибка внутреннего контракта (`TransportSendError.Faulted`).

`EnetPump.Service` — узкий вызов host_service с null event и timeout=0. После
protocol pump адаптер ограниченно извлекает готовые события через CheckEvents.
Все native операции, включая создание и Dispose, выполняет TransportOwner.
Предел прохода worker не ограничивает длительность внутреннего Service.
