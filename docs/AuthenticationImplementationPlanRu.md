# Сохранённый вход и управление доступом

- [x] SQLite: ограниченные по сроку токены входа и одноразовые коды сброса, только хеши.
- [x] AuthService: запоминание, восстановление, отзыв, сброс; общая выдача ENet-билета независимо от провайдера.
- [x] Административные операции внутри сервера, без незащищённого HTTP admin endpoint.
- [x] HTTP: remember/resume/logout/reset с существующими лимитами и HTTPS.
- [x] C++: Credential Manager, асинхронные операции UI через единственный Exchange.
- [x] Тесты сохранения после рестарта, истечения, отзыва, одноразового сброса и клиентского API.
- [x] Документация и проверка сборок/smoke.

Токен входа имеет абсолютный срок жизни; восстановление выдаёт новый одноразовый ENet-билет.
Отдельный повторный вход по паролю позволяет перевыдать токен. Смена/сброс пароля отзывает
все токены и билеты аккаунта. Steam позднее добавляет проверку доказательства и связь
provider/subject с аккаунтом; игровой протокол не зависит от способа входа.

Проверки: 308 managed-тестов, 218 C++-тестов; 20 прежних сетевых smoke-сценариев
и 4 сценария smoke_saved_auth с реальным Credential Manager/SQLite/HTTP/ENet.
Саморевью: миграция v1, отсутствие парольной зависимости в восстановлении,
отзыв in-flight билетов, коды ошибок UI, отсутствие публичного admin endpoint,
одноразовость/перевыдача/истечение reset-кода, cleanup тестовых credentials.
